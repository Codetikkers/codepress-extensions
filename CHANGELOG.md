# Changelog

All notable changes to this package are documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this package follows
[Semantic Versioning](https://semver.org/).

### Fixed
- Cookie banner: typo in the hook class name in the Readme.

## [1.1.0] - 2026-11-18

### Added
- Focal point extension: editors set the focal point of an image in the media library; images rendered with
  `'focal' => true` keep that point in view when cropped.
- Cookie banner extension with ACF options for the banner text.

### Fixed
- Cookie banner: hide the banner after the user declined cookies.
- Cookie banner: center the checkmark in the accept button.

## [1.0.0] - 2024-11-07

### Added
- ACF Gravity Form Picker: an ACF field type to pick a Gravity Forms form.
